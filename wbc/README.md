# Windows Behavior Catalog (WBC)
Windows Behavior Catalog (WBC) is a collection of fundamental behaviors for Windows OS, represented as a sequence of Windows API and/or syscalls.

We have included here a copy of the WBC in JSON format ([catalog.json](./catalog.json)).

If you want to know more about the WBC and its latest version please refer to its repository: [windows-behavior-catalog](https://github.com/reverseame/windows-behavior-catalog).
