# Windows API and Syscall categories
Classification of Windows API (WinAPI) functions and system calls (syscalls), including the Native API (NTAPI), according to their category. Presented in JSON format for you research and automation needs.

We have included here a copy of the categorization in JSON format ([winapi_categories.json](./winapi_categories.json)).

If you want to know more about the categorization and its latest version please refer to its repository: [winapi-categories](https://github.com/reverseame/winapi-categories).
