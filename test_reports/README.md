# Test reports
This folder contains some testing reports obtained from the [WinMET](https://doi.org/10.5281/zenodo.12647555) dataset and the [Windows Behavior Catalog (WBC)](https://github.com/reverseame/windows-behavior-catalog). The reports have been processed with [MALVADA](https://github.com/reverseame/MALVADA/tree/main).
